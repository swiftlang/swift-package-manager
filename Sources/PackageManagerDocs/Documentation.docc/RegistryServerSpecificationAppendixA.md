# Appendix A - OpenAPI Document

Non-normative OpenAPI (v3) description of the registry service.

The following [OpenAPI (v3) specification][OAS] is non-normative,
and is provided for the convenience of
developers interested in building their own package registry.

See [registry.openapi.yaml](https://github.com/swiftlang/swift-package-manager/blob/main/Documentation/PackageRegistry/registry.openapi.yaml).
