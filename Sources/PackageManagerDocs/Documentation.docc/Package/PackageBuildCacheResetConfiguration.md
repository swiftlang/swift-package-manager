# swift package build-cache reset-configuration

@Metadata {
    @PageImage(purpose: icon, source: command-icon)
}

Remove all build cache configuration options.

```
package build-cache reset-configuration [--global]
  [--version] [--help]
```

- term **--global**:

*Apply to the shared global configuration instead of the local package configuration.*


- term **--version**:

*Show the version.*


- term **--help**:

*Show help information.*
